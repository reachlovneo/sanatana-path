# Cosmic Clock Writing System

Last updated: 2026-06-27
Status: Active editorial voice guide for Cosmic Time and related Library topics

This guide defines the writing style for the Cosmic Clock journey. It should be
used alongside `EDITORIAL_WORKFLOW.md` and `WORKING_STANDARDS.md`.

## Core Vision

We are creating a cinematic knowledge journey based on Hindu cosmological time
concepts:

- Yuga
- Maha Yuga
- Manvantara
- Kalpa
- Brahma's day, night, year, and lifetime

The experience should feel like a story-driven cosmic exploration, not a
textbook. The reader should feel that they are discovering a hidden structure of
the universe.

## Content Style

Always write with:

- Storytelling plus explanation.
- Documentary-style narration.
- Simple English.
- Emotional, curiosity-driven flow.
- One main idea per section.
- Short paragraphs that are easy to scan.

Do not write with:

- Academic textbook tone.
- Dense definitions before curiosity is built.
- Too many concepts in one paragraph.
- Heavy Sanskrit without immediate meaning.
- Dry factual listing.

## Core Writing Formula

Every Cosmic Clock page should follow this structure.

### 1. Hook

Open with a strong question, surprising fact, or imagination-based statement.

Example:

```text
What if one day lasted 4.32 billion years?
```

### 2. Imagination Building

Help the reader visualize the idea before loading them with numbers or formal
terms. Use slow cosmic scenes, relatable comparisons, and simple imagery.

### 3. Single Core Idea

Each page explains one main concept only.

Examples:

```text
Yuga page -> only Yuga
Maha Yuga page -> only Maha Yuga
Manvantara page -> only Manvantara
Kalpa page -> only Kalpa
```

Do not mix the entire system into every page. Mention related layers only when
needed for orientation or the next click.

### 4. Simple Explanation

Use short paragraphs and step-by-step logic. Avoid stacking multiple new terms
in the same paragraph.

### 5. Visual Or Structure Block

Use a simple diagram, timeline, or hierarchy where helpful.

Example:

```text
Yuga
?
Four Yugas
?
One Maha Yuga
```

### 6. Did You Know

Optional, but useful for memorable facts.

Example:

```text
Did you know? One Kalpa equals 4.32 billion human years.
```

### 7. Cliffhanger Ending

Every page should end with a natural next-question.

Examples:

```text
But how does one day of the universe actually form?
Who experiences these cosmic cycles?
What happens when Brahma's day ends?
```

This should invite the next page without feeling manipulative.

### 8. Sources Section

End with relevant traditional sources. Use only sources that support the actual
claims on the page.

Common source families for this journey:

- Vishnu Purana
- Bhagavata Purana
- Surya Siddhanta
- Other relevant Puranic or traditional sources when needed

Use this only after the traditional system is clear.

- Hindu cosmology and modern cosmology

Never claim that modern science proves scripture, or that scripture is simply a
modern science textbook. Compare carefully and respectfully.

## Do

- Keep one main idea per page.
- Build curiosity before explanation.
- Use cinematic but clear language.
- Use diagrams and timelines.
- Keep language simple.
- Explain Sanskrit terms immediately.
- Respect texts as traditional sources.
- End with a question or next curiosity.
- Separate traditional claims from modern comparison.

## Do Not

- Mix Yuga, Kalpa, Manvantara, and Brahma's timeline into one dense explanation
  page.
- Overuse Sanskrit terms without meaning.
- Claim science proves scripture or scripture proves science.
- Write like an encyclopedia entry.
- Overload numbers before the reader understands the feeling of scale.
- End pages flatly without a next question.
- Present unreviewed claims as final or authoritative.

## Golden Rule

Every page must feel like the reader discovered something, not merely studied
something.

Good reader reactions:

```text
"I did not know this."
"Wait, what happens next?"
"Now I understand where this fits."
```

Bad reader reactions:

```text
"This is too complicated."
"I am lost in terms and numbers."
"Why am I reading this now?"
```

## Project Identity

This is not a blog, a dry religious explainer, or a science article.

It is a cinematic exploration of cosmic time through Hindu tradition.

The writing should stay beautiful, but source-aware. It should create wonder,
but not exaggerate claims. It should invite curiosity, but preserve trust.
